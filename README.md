# notext

**notext** is a simple text translator designed for learning text.

Translate any text easily and use the results to improve your language learning.

## Features

- Simple, minimal interface
- Fast text translation
- Lightweight and easy to use

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- [git](https://git-scm.com/)

### Installation

```bash
git clone git@github.com:extube/notext.git
cd notext
npm install
```

### Usage

```bash
npm start
```
